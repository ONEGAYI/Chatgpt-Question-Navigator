# ChatGPT Question Navigator

本项目是一个本地优先、隐私友好的 Chrome/Edge Manifest V3 扩展，用于在 ChatGPT 长对话页面右侧显示用户问题导航侧栏。

*插件演示视频*
https://github.com/user-attachments/assets/5de5f1df-4f4a-4e79-8f3d-142e3cd1b433

## 已实现范围

- 仅在 `https://chatgpt.com/*` 和 `https://chat.openai.com/*` 启用。
- 使用 WXT content script 和 Shadow DOM 注入右侧侧栏。
- 扫描当前 DOM 中 `data-message-author-role="user"` 的用户消息。
- 将已见过的用户消息缓存到 `chrome.storage.local`。
- SPA URL 切换时加载对应会话缓存。
- 侧栏展示 Q1、Q2 等问题摘要、mounted/cached 状态和 indexed 数量。
- 当前阅读附近的用户消息在侧栏高亮。
- 点击当前 DOM 中存在的问题可平滑跳转并临时高亮目标。
- 支持搜索已缓存问题和 hover 查看完整预览。

## 安装扩展（预打包 zip）

前往 [Releases](https://github.com/ONEGAYI/Chatgpt-Question-Navigator/releases) 页面，下载最新版本的 `chatgpt-question-navigator-*.zip`，解压到任意文件夹，然后按下方浏览器说明加载。

### Chrome 加载方式

1. 打开 `chrome://extensions/`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择解压后的文件夹。
5. 打开 ChatGPT 页面验证右侧导航侧栏。

### Edge 加载方式

1. 打开 `edge://extensions/`。
2. 开启左侧「开发人员模式」。
3. 点击「加载解压缩的扩展」。
4. 选择解压后的文件夹。
5. 打开 ChatGPT 页面验证右侧导航侧栏。

## 从源码构建

### 安装依赖

```bash
pnpm install
```

如果没有 pnpm：

```bash
npm install
```

### 开发运行

```bash
pnpm dev
```

### 类型检查

```bash
pnpm compile
```

### 构建扩展

```bash
pnpm build
```

构建完成后，产物会自动拷贝到 `%TEMP%\Chatgpt-Question-Navigator`（即系统临时目录下的 `Chatgpt-Question-Navigator` 文件夹）。原始构建产物仍保留在 `.output/chrome-mv3`。

> **为什么拷贝到临时目录？** 当使用 git worktree 在多个分支间并行开发时，每个工作树有独立的 `.output` 目录。浏览器只需固定加载临时目录中的副本，切换工作树后重新 `pnpm build` 即可更新，无需反复修改扩展加载路径。

## 隐私说明

扩展不调用 ChatGPT 内部 API，不 monkey patch fetch/XHR，不请求 `<all_urls>` 权限，不添加 analytics，也不会把聊天内容上传到任何服务器。已采集的问题摘要和搜索文本只保存在浏览器本地的 `chrome.storage.local`。

## 首次对已有对话使用

插件通过实时扫描 DOM 来缓存消息，对于打开前就已经存在于页面中的历史对话，**不会自动索引全部消息**——只有你滚动经过的部分才会被缓存。

如果你打开一个已有很长聊天记录的对话，希望侧栏立刻显示完整的消息索引，请使用「重新采集」功能：

1. 打开目标 ChatGPT 对话页面。
2. 在右侧导航侧栏顶部，点击 **「重新采集本对话」** 按钮。
3. 插件会自动从页面底部向顶部滚动，逐帧采集所有用户问题和 AI 回复。
4. 采集期间如需中断，再次点击同一按钮即可取消。

采集完成后，侧栏会一次性展示完整的消息列表（按对话顺序排列），此后正常浏览时增量更新即可。

> 采集过程会自动滚动页面，期间你可以随时中断，已完成的部分会保留。如果页面刷新，插件会自动检测并恢复上次未完成的采集。

## Popup 配置菜单

点击浏览器工具栏的扩展图标，打开 Popup 面板，提供以下管理功能：

![插件菜单](assets\插件菜单.png)

### 存储用量

顶部显示当前扩展占用 `chrome.storage.local` 的空间（上限 8 MB），以进度条形式呈现。超过 70% 显示警告色，超过 90% 显示危险色。

### 滚屏速率

三档切换，影响「重新采集」和「渐进式跳转」的速度：

| 档位 | 说明 |
|------|------|
| **标准** | 最慢但最稳定，适合网络/渲染较慢的场景 |
| **快速** | 适中速度，兼容性与效率的平衡 |
| **极速** | 最快速度，**默认档位**，适合大多数场景 |

也可以在 ChatGPT 页面通过快捷键 **Ctrl+Shift+S** 循环切换。

### 缓存对话列表

显示所有已缓存对话的 ID、消息条数和最后更新时间。每条记录右侧有删除按钮，可逐条清理单个对话的缓存。

### 操作按钮

- **LRU 清理** — 按最近最少使用策略自动淘汰旧缓存，释放空间。
- **清空全部** — 删除所有已缓存的对话数据（需二次确认）。

## 如何中止跳转

点击侧栏中的消息后，插件会将页面滚动到目标位置。对于距离较远的消息，可能需要多次渐进式滚动才能到达。以下操作可以随时中止正在进行的跳转：

- **按 Esc 键** — 立即取消当前跳转。
- **手动滚动页面** — 使用鼠标滚轮、触摸板、键盘方向键或拖动滚动条，任意方向的滚动都会中止跳转。
- **点击另一条消息** — 会取消当前跳转并开始跳转到新目标。

中止后，侧栏底部的跳转进度提示会消失，页面停留在当前位置。

## 已知限制

- 扩展无法读取从未在 DOM 中出现过的历史消息，需使用「重新采集」功能（见上方说明）。
- 首次打开超长对话时，未滚动到的区域不会被自动缓存。
- ChatGPT 页面结构变化可能导致 DOM 识别失效。
- cached-only 消息支持渐进式远距离跳转（最多 200 次尝试）。
